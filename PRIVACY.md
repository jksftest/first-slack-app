# Privacy Policy

_Last updated: September 25, 2026_

first-slack-app is a test app built for learning the Slack app submission process. It is not intended for production use.

## What we collect

- **Installation data:** when a workspace installs the app, we store the OAuth tokens and workspace/user IDs that Slack provides, so the app can respond to events.
- **Messages and events:** the app receives messages in channels it's added to and App Home events. These are processed in memory to respond and are not stored.

## How we use it

Data is used only to operate the app's features inside Slack. We do not sell, share, or use data for advertising.

## Retention and deletion

Installation data is deleted when the app is uninstalled. To request deletion, email jksftest@gmail.com.
